# SpinksWorld Mobile (Static React)

This repository contains a mobile-first static React prototype inspired by **https://www.spinksworld.com/**.

## Features

- Phone-first UI shell and card-based content layout.
- Quick actions area with direct link to SpinksWorld.
- Pure static hosting approach (no build step required).

## Run locally

```bash
python3 -m http.server 4173
```

Then open: `http://localhost:4173`
